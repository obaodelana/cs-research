## \[Reading\] [[Inductive Representation Learning on Large Graphs]]
### Algorithm 1 (Embedding generation)
```python
def gen(G: Graph, X: dict[Vertex, Feature],
		depth: int, weights: list[Matrix],
		σ: Function, agg: list[Function]):
	h = {} # Vector representations of vertices
	for v in G.vertices:
		h[(v, 0)] = X[v] # First repr. is just the feature vector

	for k in range(depth):
		for v in G.vertices:
			# Aggregate all neighbouring information from previous step into this vector representation
			h[(v.neighbours, k)] = agg[k]([h[(u, k-1)] for u in v.neighbours])
			# We first concatenate previous vector representation and vector representing information from neighbouring vectors
			# We then pass that vector through a fully connected layer
			h[(v, k)] = σ(weights[k] * concat(h[(v, k-1)], h[(v.neighbours, k)]))
			# Normalize vector
			h[(v, k)] = h[(v, k)] / norm(h[(v, k)])

	# Return the representations after `depth` aggregations
	return [h[(v, depth-1)] for v in G.vertices]

```
