## Paper 1: [[Exact Matrix Completion via Convex Optimization]]
This paper attempts to solve the problem of filling missing entries in a matrix. The matrix is assumed to be *low rank*, i.e.,
- Singular (non-invertible)
- The column (or equivalently, row) space of the matrix is of low dimension
The final matrix is that with the ==minimum nuclear norm== agreeing with the non-missing entries.

The concept of **degrees of freedom** of a matrix justifies the low-rank assumption.

The degrees of freedom of a matrix tell us the number of matrices that can be formed by changing the entries of a matrix. Well, each entry can take on infinite values, so we really mean the number of ways we can change the values of the matrix without altering the matrix's form. For example,
- If we have a $m\times n$ matrix, the degrees of freedom is $mn$. In this case, there are no constraints on the form of the matrix.
- If, however, we have a upper/lower triangular matrix, we know that several values of the matrix have to be zero, so now, the degrees of freedom reduces (i.e., there are more constraints.) For a $n\times n$ lower triangular matrix, the last row can have $n$ non-zero values, the next row $n-1$ up until the first row, which only has $1$ non-zero value. In total, we have $\sum_{i=1}^n i = \frac{n(n+1)}{2}$ degrees of freedom. [(Source)](https://math.stackexchange.com/questions/2771591/degrees-of-freedom-for-a-matrix)
- More generally, if we have a square matrix with rank $r$, then WLOG, only the first $r$ columns are linearly independent. Hence, we can have $nr$ different values for the first $r$ columns, and $r(n-r)$ values for the remaining ($r$ denotes the number of coefficients needed to uniquely represent a column using the independent columns.) Therefore, the degrees of freedom is $r(n + (n-r)) = r(2n-r)$. [(Source)](https://math.stackexchange.com/questions/45159/how-to-calculate-the-degrees-of-freedom-of-an-r-ranked-matrix-with-the-size-be)

## Paper 2: [[Inductive Representation Learning on Large Graphs]]
Node embeddings "represent nodes in a continuous vector space, preserving ...relational information from the graph" [[Watch Your Step - Learning Node Embeddings via Graph Attention|(1)]].
- Current methods are **non-generalizable** and can only be used on already-seen graphs. These *transductive* representations work well when we are trying to classify a given set of unlabelled nodes in a known graph with already labelled nodes (e.g., content recommendation.) That is, for predictions to be made, the unlabelled nodes need to be present during training.
What happens when a new YouTube video is uploaded? Using a transductive approach, we would have to re-train on the graph with this new node included to generate an embedding and make predictions.

This paper introduces an *inductive* approach, where the focus is on generalization.

>Instead of training individual embeddings for each node, *we learn a function that generates embeddings* by sampling and aggregating features from a node’s local neighbourhood.

So, they are able to generate embeddings for unseen nodes and even entirely new graphs using these learned functions. These functions incorporate node features and structural information (e.g., node degree) to learn (1) the topological structure of each node's neighbourhood and (2) the distribution of a node's features in its neighbourhood.
