My supervisor recommended an online course called [Deep Learning DIY](https://dataflowr.github.io/website/). I'm currently doing module 1.
### Module 1
The instructor outlines a typical [[Supervised Learning]] setup
1. Prepare a dataset
2. Turn datapoints into vectors. This is called [[Feature Extraction]]. In a supervised learning setup, this is normally **done by experts**.
3. Pass [[Vector Embedding|vectors]] into [[Model|model]] for [[Training|training]].
4. [[Learning]] is done by comparing model's output with ground truth, and modifying the model's parameters according to some [[Loss Function]].

However, in [[Deep Learning]], we also attempt to learn vector embeddings, as well as the model.
### Deep Learning Pipeline
- Loading the dataset with a [[Dataloader]].
- Learn features.
- Calculate loss of model, and optimize to minimize loss.
